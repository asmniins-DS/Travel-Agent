🎯 READY TO RUN
═══════════════════════════════════════════════════════════════════════════

To get started:

1. Get your OpenAI API key from: https://platform.openai.com/api-keys

2. Create .env file:
   $ cp .env.example .env

3. Edit .env and add your API key:
   OPENAI_API_KEY=sk-...your-key-here...

4. Activate environment:
   $ source venv/bin/activate

5. Run the agent:
   $ python travel_agent.py
